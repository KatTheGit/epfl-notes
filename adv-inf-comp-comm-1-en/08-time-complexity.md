# Complexity

Weird terminology regarding complexity

## Class P

A problem is of **class p** or **tractable** if there exist an algorithm that for an input of size $n$ produces the result with $O(n^d)$ operations.

- max element
- search
- sort

## Class NP

**Nondeterministic Polynomial Time**. Problems for which the correctness of a proposed solution can be **verified** in **polynomial time** (class P). (But no polynomial solution found)

### NP-Complete Problems

A problem for which, if a solution was to be found, all other NP problems would be proven to be solveable in polynomial time.
